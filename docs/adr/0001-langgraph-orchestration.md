# ADR-0001：使用 LangGraph 编排评测工作流

- 状态：accepted
- 日期：2026-08-04

## 背景

系统需要先调用被评测模型产生待评回答，再执行显式主从裁判通信、并行子裁判、
状态隔离、失败恢复和可审计的节点执行记录。
核心数据协议还必须独立于具体 Agent 框架，避免公开数据 Adapter 和模型 Provider
被编排库绑定。

## 决定

使用 LangGraph 表达评测图和 Checkpoint。所有图状态、节点输入和节点输出使用
Pydantic 模型定义；领域协议放在独立包中。数据 Adapter、模型 Provider 和聚合算法
不直接依赖 LangGraph 类型。

图中必须包含独立的 Target Model 节点。Target Model 的回答固化后才进入主裁判节点；
后续子裁判评价同一回答，不能各自重新生成回答。

## 后果

- 可以显式检查 fan-out/fan-in、失败恢复和子图隔离。
- 需要自行实现评测领域的协议与确定性聚合器。
- 如果以后替换编排框架，数据层和模型层仍可复用。
- 不把“Agent 数量”当作复杂度指标；只有职责和输入隔离明确时才拆分节点。
