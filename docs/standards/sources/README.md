# Standard source artifacts

This directory is reserved for standard documents or excerpts whose redistribution is
explicitly permitted. Use one subdirectory per official `standard_id`, and record every
committed artifact's repository path and SHA-256 in its taxonomy TOML source entry.

Do not place restricted or license-unknown standard text here. For those sources, keep only
the official URL, access date, bibliographic metadata, and optional externally computed
document hash in `config/taxonomies/*.toml`.
